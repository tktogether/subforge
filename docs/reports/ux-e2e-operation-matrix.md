## 4. 判定与缺陷分级

- **PASS**：与预期一致（附截图编号）。
- **FAIL**：与预期不符 → 记缺陷，附截图 + DOM 文案 + 浏览器网络记录。
- **OBS（观察项）**：设计上有争议但不影响功能（文案、交互习惯、信息层级）。
- **BLOCKED**：环境不可用（服务 500、页面白屏）→ 立即停下报 Lead，不得继续盲测。
- 缺陷分级：**P0** 核心链路中断（无法建令牌/无法转换/登录死锁）；**P1** 功能错误或数据错乱；**P2** 交互与文案错误；**P3** 视觉与一致性。
