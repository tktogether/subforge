设计说明

色彩系统

单一强调色 #215da5（浅）/ #4b78ba（深）+ 带蓝相中性灰；每变量同时给出 hex 与 OKLCH；深色底 #0d0f12（#0f0f0f 系列，禁用纯黑）。

对比度

正文/表面 16.02:1（浅）/ 13.77:1（深）；主按钮文字/底色 6.43:1（浅）/ 5.91:1（深），hover 8.32:1（浅）/ 8.40:1（深），全部 ≥ AA 4.5:1（深色 hover 底色由 --sf-accent-strong #1f4c85 提供）。

间距与圆角

间距仅用 4/8 的倍数（4/8/12/16/24/32/48/64）；圆角上限 6px；以 1px 细边框分层，不使用阴影。

字体

意图字体栈 + 本地兜底；生产环境优先 woff2；同页 2 字体（正文 + 等宽）；数字统一 tabular-nums。

动效

统一 cubic-bezier(0.16, 1, 0.3, 1)；微交互 150ms；页面过渡 400ms；skeleton 500ms；prefers-reduced-motion 下降级为近零时长。

可访问性与反模式

:focus-visible 为 2px 实线 outline + 2px 偏移；空状态给原因与下一步；错误文案具体可操作；无毛玻璃、无 emoji 文字图标、无 >1px 侧边色条、无嵌套卡片、无 hero 大指标、无正文全大写。
